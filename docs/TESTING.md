# Testing / Bug reports

Baseline: Blood & Glory 1.1.6, Revival V4 and V5 LIGHT, Android 15, Redmi device tanzanite.

## Confirmed on one device

- Main menu and combat are playable.
- Ordinary in-game shopping works.
- V5 LIGHT launches and the user reports that the game runs.
- APK of 18,926,266 bytes and OBB of 131,667,125 bytes were pulled from the installed phone.
- XAPK was assembled and file hashes checked by the local export tool.

## Not yet confirmed

- Glu Points reward amounts, award conditions, and duplicate prevention.
- Currency persistence across game restarts.
- Complete offline startup in airplane mode.
- Replacement behavior for old Glu special offers.
- Clean install from phone-exported XAPK and operation on other devices.
- Retention of private saves after reinstalling APK.

For a bug report include phone model, Android version, build, what you did, expected and observed behavior, and a crash-log excerpt if available. Remove personal information from logs.
